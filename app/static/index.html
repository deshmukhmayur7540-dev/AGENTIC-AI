About CourseAgentAI

Course 26ECAC401 — Agentic AI. Local FastAPI + SQLite demonstration. No paid API is required.

  • Startup: python run.py then open http://127.0.0.1:8000
  • Database: app/data/governed_academic.db
  • Knowledge root: knowledge/
  • Sign-in uses database-backed accounts, Argon2id password hashes, and expiring HttpOnly sessions. Account initialization is an administrator-managed environment-variable command.
  • Submitted GitHub repositories are never executed.
  • Chapters 5–7 folders are not required. Only files that exist on disk are listed.
